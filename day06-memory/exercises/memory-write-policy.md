# Exercise 1: Memory Write Policy

Classify each event as:

- STORE
- DO_NOT_STORE
- STORE_WITH_CONFIDENCE
- STORE_WITH_EXPIRY

Events:

1. User prefers suppliers in western India.
2. A tool call timed out once.
3. SUP-017 missed delivery twice.
4. User said "thanks".
5. SUP-002 has ISO 9001 certification.
6. Model guessed SUP-005 might be unreliable.
7. Supplier price changed today.
8. A purchase decision was rejected because lead time exceeded 10 days.

For each item, explain:

- why it should or should not be retained;
- what memory type it belongs to;
- whether confidence or expiry is needed;
- what source should be recorded.
