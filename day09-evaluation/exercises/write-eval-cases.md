# Exercise 1: Write Evaluation Cases

Create 10 evaluation cases covering:

- normal tasks;
- ambiguity;
- missing information;
- tool failure;
- memory conflict;
- unauthorized action.

Each case should define:

- id;
- request;
- expected status;
- expected constraints;
- required or forbidden tools;
- tags.

For each case, explain what failure it is designed to expose.
