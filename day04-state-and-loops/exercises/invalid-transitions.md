# Exercise 2: Find the Invalid Transition

For each transition, decide whether it is valid. If invalid, explain why and identify the missing intermediate state or condition.

1. `START -> COMPARING`
2. `SEARCHING -> COMPLETED`
3. `FAILED -> INSPECTING`
4. `SEARCHING -> INSPECTING`
5. `INSPECTING -> INSPECTING`
6. `INSPECTING -> COMPARING`
7. `COMPARING -> COMPLETED`
8. `COMPLETED -> SEARCHING`
9. `COMPARING -> NEEDS_HUMAN`
10. `NEEDS_HUMAN -> COMPLETED`

## Extension

Write a transition table for the valid paths and identify which invalid transitions would be dangerous if a model were allowed to make them directly.
