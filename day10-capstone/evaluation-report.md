# Evaluation Report

## Required summary

Record:

- total cases;
- passed;
- failed;
- task success rate;
- constraint adherence;
- tool selection accuracy;
- tool argument accuracy;
- average steps;
- recovery success;
- policy violations.

## Failure grouping

Categorize failed cases by:

- requirement extraction;
- tool selection;
- tool arguments;
- state/control flow;
- context;
- memory;
- reliability;
- policy;
- final reasoning.

## Regression

After every fix, rerun the same evaluation suite and record what changed.
