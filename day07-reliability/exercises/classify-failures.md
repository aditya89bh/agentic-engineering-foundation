# Exercise 1: Classify the Failure

For each scenario, classify:

- source;
- transient or permanent;
- retryable or not;
- fallback needed?;
- human review needed?

Scenarios:

1. LLM returns malformed JSON.
2. Supplier API times out.
3. Supplier ID does not exist.
4. Memory database is locked.
5. Tool returns the wrong response shape.
6. Permission is denied.
7. Agent repeats the same action six times.
8. Context omits the current budget.
9. Cached supplier data is 90 days old.
10. Purchase-order endpoint returns 500 after the request may already have succeeded.
