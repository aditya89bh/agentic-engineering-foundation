# Exercise 1: Select Context

For each decision type below, choose what belongs in context and what should be excluded.

Available information:

- user goal;
- current budget;
- old budget;
- supplier search results;
- inspected supplier details;
- unrelated conversation;
- failed tool trace;
- current status;
- all tool definitions;
- only tools valid for the current state;
- duplicate supplier observations;
- recommendation draft.

Decisions:

1. SEARCH
2. INSPECT
3. COMPARE
4. FINISH

For each decision, record:

- keep;
- remove;
- compress;
- why.

The important question is: **what information can actually change the next action?**
